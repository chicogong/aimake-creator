# Aimake Studio · 字标再设计 4 款方案深度评估与应用规范

基于「创作画布 (Creator Canvas)」与四色几何图形标（紫、黄、珊瑚红、浅薰衣草），本套字标提供了 4 款不同气质的矢量化字体方向。所有字体字母均已转曲为矢量轮廓路径（SVG），不依赖系统字体安装。

---

## 落地使用分工

1. **工程与主站定位**：
   - 在静态官网导航、CLI 启动 Banner 与 GitHub 文档中，优先采用 **01 Editorial** 与 **彩色几何标徽 (`symbol-color.svg`)** 的组合，传递 Local-First 严谨、高品质的工程师气质。
2. **多模态与社交卡片**：
   - 在生成的 OpenGraph 社交卡片 (`assets/brand/social/og-cover-1200x630.png`) 与 GitHub 宣传图上采用 **03 Duotone**，第一眼强化 “AI + 创作 (Make)” 的核心心智。
3. **资产目录清单**：
   - 矢量轮廓源文件：`assets/brand/wordmarks/svg/aimake-0{1,2,3,4}-*.svg`
   - 高清透明底 PNG：`assets/brand/wordmarks/png/aimake-0{1,2,3,4}-*-{1200w,2400w}.png`
   - 效果对照图：`docs/brand-kit/wordmarks/aimake-wordmarks-overview.png`
