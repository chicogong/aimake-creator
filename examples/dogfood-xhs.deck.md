# AI 智能体时代：为什么我们不再需要云端排版工具？

## 基于 Aimake 对话副驾驶，本地编译一键生成

- 云端工具先要账号、再把素材搬上服务器；本地优先让 Markdown 与 .deck.md 始终是唯一真相源

- 16+ AI 宿主（Claude Code、Cursor、Codex 等）用各自订阅直接写 .deck.md，CLI 只做确定性编译

- 结构化卡片即时预览：改一行文本即重编译，不依赖服务端渲染

```compare
云端排版 :: 强制登录 | 素材上传云端 | 按月订阅 | 导出受平台限制
Aimake 本地 :: 无需账号 | 文件留在本机 | 复用已有订阅 | 16+ 宿主可编译
```

::: speech
做一页幻灯片，为什么还得先登录一个网站？云端排版把你的文字和图片都搬进它的服务器，改一次就得等一次渲染。AI 智能体时代其实可以换个做法：让 Claude Code、Cursor 这些助手用你自己的订阅，把内容写进一个 .deck.md 纯文本文件。Aimake 只做一件事——在本地、确定性地把它编译成卡片和 3:4 竖版画面。没有账号，没有后端，文件全程不出本机。改一行字，立刻重编，所见即所得。排版这件事，该回到你自己的电脑里了。
:::
