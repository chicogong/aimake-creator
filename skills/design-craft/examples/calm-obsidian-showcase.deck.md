# 静默设计的力量：让工具退居幕后
## 剔除浮夸的霓虹渐变与营销噪点，以瑞士网格与黑曜石景深重构专业软件尊严。

::: grid cols-3 gap-6
::: card col-span-2 surface-elevated
#### 瑞士国际主义排版系统
基于 8pt 基线与严格 12 栏数学模数构建。大反差标题配合大面积呼吸留白，实现视觉张力。

```metric
- 基线节律: 8px 绝对吸附
- 孤字悬挂: 0 容忍 (text-wrap: balance)
- 表格数字: Tabular Nums 无抖动对齐
```
:::

::: card col-span-1 surface-card
#### 黑曜石暗房景深
多层深黑曜石微渐变与 1px 发丝倒角折射，杜绝刺眼纯黑与泥泞磨砂。

- `#090a0f` -> `#141721` 层次渐进
- 1px 发丝边框与内嵌高光
- 物理阻尼弹性交互 (180ms)
:::
:::

::: speech
每一处间距与字距的精准校准，都是对创作者认知资源的最高尊重。
:::

# 浮夸喧闹 vs 静默精工

```compare
AI 塑料感 (Loud AI Slop) :: 刺眼霓虹蓝紫渐变 | 满屏闪烁的 ✨ 魔法星星 | 虚构的“颠覆与秒杀”黑话 | 随意杂乱的卡片拼凑
静默工艺 (Calm Craft) :: 深度黑曜石与建筑纸灰 | 精密的 1.25px 几何线框 | 真实可度量的工程参数 | 严格吸附的 8pt 瑞士网格
```

::: speech
真正的专业感从来不需要通过喧闹的特效来证明自身。
:::
