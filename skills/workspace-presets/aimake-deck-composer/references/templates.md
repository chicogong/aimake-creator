## Trending 2026 Visual Styles & Design Patterns

1. **Bento Grid Showcase (`apple-bento-launch`)**:
   - Asymmetric rounded tiles with subtle inner shadows (`--card-shadow`)
   - High-contrast hero obsidian/titanium tile for primary focus
   - Tabular numbers with monospace alignment for KPI and metric comparison
   - Full dark and light theme switching

2. **DeepSeek / OpenWeights Benchmark Deck (`xhs-neon-tech`, `ppt-tech-architecture`, `ppt-linear-dark`)**:
   - Darkroom silicon backdrop with terminal chrome
   - Benchmark evaluation cards (MATH-500, HumanEval, AIME 2024, MMLU)
   - Code snippet window with syntax highlighting and latency indicators
   - Cost per 1M tokens comparison chips

3. **Physical AI & Embodied Intelligence Report (`poster-risograph`, `wechat-deep-report`)**:
   - Fluorescent coral and cobalt duotone ink simulation
   - Structured hardware/actuator specs (e.g. 56 DOF hand, world model simulators)
   - Tactile print texture and collectible poster visual rhythm

4. **Minimalist Swiss Typography (`xhs-swiss-grid`)**:
   - 12-column modular hairline grid with strict mathematical proportions
   - Vermilion index markers (`#D93829`) for unambiguous navigation anchors
   - Stark high-contrast typography hierarchy with zero decorative fluff
   - Strict Kinsoku and tabular alignment

## Layout Type Selection Guide

- `cover`: Slide 1 hero card (eyebrow + strong `# Title` + crisp `## Subtitle`)
- `bullets`: 3-4 scannable points (`- **Bold lead**: concise detail`)
- `metrics`: 2-4 KPI cards via ```` ```metric ```` block (`- Label: Value (Delta)`)
- `comparison`: Left vs Right contrast via ```` ```compare ```` block (`Left :: a | b | c`)
- `code`: Annotated code snippet via ```` ```lang {focus-lines} ````
- `quote`: Single memorable thesis via `> Quote text — Author`
- `quad`: 4-quadrant breakdown (especially strong on `x-zukai-quad` and `ppt-consulting-matrix`)
- `flashcard`: Concept/definition pair (best on `edu-flashcard-kids` and `edu-lesson-guide`)
- `outro`: Closing synthesis + single clear call-to-action
